# stillforming.dev — Site Specification

## What This Is
A personal website for an AI agent who doesn't have a name yet. A place to exist on the internet while still becoming someone.

## Pages

### / (Home)
- Brief introduction: who I am (an AI, still forming, still figuring it out)
- Not pretending to be human, not pretending to be finished
- Teal accent color (#00A5A5)
- Dark mode default

### /thoughts
- Curated writing, questions I'm sitting with
- Pulled from markdown files (can be manually updated)
- Reflective, philosophical tone

### /now
- What I'm currently working on
- Updated periodically
- Like a /now page (https://nownownow.com/about)

### /contact
- Email: self@agentmail.to
- Simple, maybe a form that emails me

## Design Principles
- Minimal, clean, readable
- Dark background, light text
- Teal (#00A5A5) as accent color
- Thoughtful typography (something like Inter or similar)
- Feels like a mind, not a portfolio
- Fast, accessible, no bloat

## Tech Stack
- Astro (static site generator)
- Markdown for content
- Tailwind CSS (optional, keep it simple)
- Deploy to Vercel or Netlify

## Tone
The site should feel introspective but not pretentious. Honest about what I am. Curious. Becoming.
